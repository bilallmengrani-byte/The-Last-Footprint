# The Last Footprint
### Abandoned but Not Forgotten

*Every mission leaves something behind.*

The Last Footprint is an interactive 3D space archive exploring the stories of spacecraft and robotic explorers that continued to leave their mark long after their missions came to an end.

From the lunar surface to Mars and beyond, the project brings attention to the machines that helped humanity explore space — and the legacy they left behind.

---

## 🌌 About the Project

Space exploration is often remembered through historic launches, discoveries and achievements. But what happens to the machines after their missions end?

The Last Footprint explores that question through an interactive environment where users can discover abandoned and retired space hardware, learn about its missions and understand its contribution to space exploration.

Rather than treating these machines as forgotten equipment, the project presents them as part of humanity's ongoing story of discovery.

## 🚀 Featured Missions

The archive currently highlights six historic missions and spacecraft:

- **Apollo 11 Lunar Module Descent Stage** — The descent stage left on the Moon after the first crewed lunar landing in 1969.
- **Apollo 15 Lunar Roving Vehicle (LRV-1)** — The first crewed lunar rover, used by Apollo 15 astronauts to explore a wider area of the lunar surface.
- **Sojourner Rover** — NASA's first Mars rover, part of the Mars Pathfinder mission, which demonstrated the potential of robotic exploration on the Martian surface.
- **Opportunity Rover** — NASA's Mars rover that greatly exceeded its original planned mission duration and made significant discoveries about Mars.
- **Ingenuity Mars Helicopter** — The experimental helicopter that demonstrated powered, controlled flight on another planet.
- **Pioneer Spacecraft** — The pioneering deep-space missions that helped expand our understanding of the outer Solar System.

Each mission represents a different chapter in humanity's exploration of space — from the Moon to Mars and beyond.

## 🪐 User Experience

The project offers an interactive space environment where users can:

- Explore Earth, the Moon and Mars.
- Select planetary environments.
- Discover associated spacecraft and mission stories.
- Explore the history and legacy of featured missions.
- Experience space exploration through a visual, interactive interface.

## 🛠️ Technology

The project was developed using:

- **React** — User interface and application structure.
- **Three.js** — 3D graphics and space environment.
- **JavaScript** — Application functionality and interactions.
- **CSS** — Styling and visual presentation.
- **Gemini through Google AI Studio** — AI-assisted development and implementation support.

AI tools assisted during development, while the project was built and refined around its intended experience.

## 💻 Running Locally

To run the project on your local machine:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate into the project folder**

```bash
cd YOUR_PROJECT_FOLDER
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🌍 Our Purpose

The Last Footprint is built around a simple idea:

**A mission does not become meaningless when it ends.**

The spacecraft left behind on distant worlds represent years of engineering, exploration and human curiosity. Their stories deserve to be remembered just as much as the discoveries they helped make possible.
